# Folder Images / Gambar

Folder ini digunakan untuk menyimpan aset gambar lokal Risss.clobber:

- `products/` : Foto produk katalog (Stone Island, C.P. Company, Adidas, Ellesse)
- `brands/`   : Logo atau aset visual brand
- `banners/`  : Banner promo dan penawaran khusus
- `hero/`     : Gambar latar belakang / hero section
