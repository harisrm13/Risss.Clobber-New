# Hero Section — Panduan Format Gambar

Letakkan gambar banner hero utama di folder ini:

## Nama & Format File:
- **`hero.png`** (sedang aktif digunakan) atau **`hero.jpg`**

## Rekomendasi:
- Resolusi: Minimal `1600 x 900 px` (atau `1920 x 1080 px` untuk Full HD).
- Rasio: 16:9 atau ultrawide.
- Komposisi foto: Memiliki pencahayaan seimbang (sedikit gelap atau netral) agar teks judul putih di atasnya mudah terbaca.
- Ukuran file: Di bawah 1 MB (gunakan kompresi web jika memungkinkan) agar loading cepat.
