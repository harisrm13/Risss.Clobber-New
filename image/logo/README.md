# Logo Website — Panduan Format

Letakkan file logo website Risss.clobber di folder ini:

## Nama & Format File yang Didukung:
- **`logo.png`** (Direkomendasikan dengan background transparan)
- Atau **`logo.svg`**

## Rekomendasi:
- Warna teks/ikon logo: Putih / Terang (karena navbar website bernuansa gelap).
- Rasio: Horizontal / Lanskap (misal perbandingan 3:1 atau 4:1).
- Resolusi minimal: Lebar 300px - 600px (tinggi 80px - 160px).
